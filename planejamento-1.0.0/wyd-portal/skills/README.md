# Skills do `wyd-portal` — roteador

Portal web do jogador em Next.js: conta, personagem, mercado e conteúdo. Fala com o banco por rota de
servidor; o navegador nunca recebe credencial.

| Tarefa | Skill | Quando não usar |
|---|---|---|
| implementar página, rota ou server action do portal | [`execution/implementar-rota-portal`](execution/implementar-rota-portal/SKILL.md) | a mudança é do backoffice (`wyd-admin`) |
